Observed Inventor tolerance behavior:

- `Tolerance.SetToDefault()` changes `ToleranceType` to `kDefaultTolerance`.
- `SetToDefault()` resets `Upper` / `Lower` to `0`.
- Previously assigned `HoleTolerance` / `ShaftTolerance` strings may remain readable.
- Runtime records this factual API state and does not compensate or clear strings.

Verified export command:

- `export_pdf` exports the active Autodesk Inventor `DrawingDocument` through the PDF Translator Add-In and `TranslatorAddIn.SaveCopyAs`.
- `export_dwg` exports through the DWG Translator Add-In with a caller-supplied DWG INI.
- `export_dxf` exports through the DXF Translator Add-In with a caller-supplied DXF INI.
- Export commands require explicit output paths.
- Export commands block existing files unless `overwrite=true`.
- Export commands verify output file existence.
- Export commands return file size and timestamp facts where available.
